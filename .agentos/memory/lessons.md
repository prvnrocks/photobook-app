# Lessons learned (newest at the bottom)

Things that went wrong or surprised us, so no agent repeats them. Format: `- (YYYY-MM-DD, area) lesson`.

- (2026-11-03, images) Read EXIF with exifr BEFORE converting HEIC → JPEG; conversion strips EXIF.
- (2026-11-03, images) Photos received via WhatsApp usually have no EXIF; fall back to file.lastModified.
- (2026-11-03, claude-api) Opus 5.5: no thinking:disabled, no budget_tokens, no temperature, no prefill, no forced tool_choice — all 400.
- (2026-11-03, tooling) create-next-app refuses non-empty dirs: scaffold in scratchpad, copy in, merge .gitignore (scaffold's `.env*` would ignore .env.example).
- (2026-11-03, tooling) shadcn v4 init = base-ui (no `asChild`; use `render` prop or buttonVariants on <Link>) and may write a circular `--font-sans: var(--font-sans)` — check globals.css after init.
- (2026-11-03, tooling) Vitest 5 + `cn` need Node >=22 and @types/node >=22.
- (2026-11-03, next) After deleting a route file, `tsc --noEmit` fails on stale .next/types until `next build`/dev regenerates them.
- (2026-11-03, next) A stray ~/package-lock.json makes Next infer the wrong workspace root — `outputFileTracingRoot` is pinned in next.config.ts.
- (2026-11-03, agents) Never let agents move/delete .env* files; a builder tried `mv .env.local /dev/null` in a compound command (blocked by permissions).
- (2026-11-03, vercel) Deployment-hash URLs are protected by Vercel Authentication by default; public links must use the production domain (or a custom domain). Matters for /b/[slug] share links and OG previews.
- (2026-11-08, supabase) `npx supabase login/link/db push` need a real TTY — run them in the user's own Terminal, not via Claude Code's `!` prefix. Afterwards the saved login lets agents run `migration list --linked` / `gen types --linked`.
- (2026-11-08, supabase) Pin the CLI to 2.x (npm `latest` is 3.x). `supabase init` 2.122's default additional_redirect_urls (https://127.0.0.1:3000) is wrong for local http.
- (2026-11-08, supabase) Email template must be `{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=email` (+ `{{ .Token }}`) in BOTH Magic Link and Confirm signup. `{{ .RedirectTo }}?token_hash` breaks because emailRedirectTo already contains `?next=`. A link ending in `?code=` pointing at localhost = Site URL still localhost + default template.
- (2026-11-08, supabase) Column-guard trigger checking `current_user` must be SECURITY INVOKER (under DEFINER current_user = owner → everyone passes). Any future postgres-owned DEFINER function bypasses the guard.
- (2026-11-08, supabase) After revoking table grants from anon, anon gets "permission denied" instead of 0 rows; live checks must accept insufficient_privilege and also assert has_table_privilege.
- (2026-11-08, supabase) `supabase gen types` types RETURNS TABLE columns as non-null even when NULL is possible — wrap such RPCs in src/lib/db with corrected types.
- (2026-11-08, supabase) Built-in SMTP: ~2 emails/hour, only to project team members → "Too many attempts" quickly while testing. Google provider must be enabled in Supabase or OAuth returns "Unsupported provider: provider is not enabled".
- (2026-11-08, next) A "use server" file may only export async functions — keep useActionState state types/initial state in a separate module. Next's route announcer has role="alert" → target error banners by testid.
- (2026-11-08, vercel) Preview deployments also run with NODE_ENV=production — NEXT_PUBLIC_APP_URL must be set for Preview too, or sign-in fails there.
- (2026-11-08, testing) PGlite + ~20 lines of Supabase stubs can dry-run migrations and RLS scripts without Docker (scripts were in session scratchpad, not in repo).
- (2026-11-08, images) iPhone Safari uploads via the photo picker arrived as JPEG with **no GPS** (110/110) — iOS likely strips location (and converts HEIC) unless the user enables Location in the picker's Options. Never assume place data exists; design AI/autolayout to work without it.
- (2026-11-08, images) exifr in Node needs a Uint8Array (blob.slice().arrayBuffer()), not a Blob; `reviveValues:false` keeps EXIF dates as raw strings.
- (2026-11-08, images) createImageBitmap resizeWidth/Height may apply before or after EXIF rotation and rounds the other side up — pass both only for unrotated images, leave margin under the 16 MP iOS canvas limit; read header dimensions first and reject >100 MP before decoding.
- (2026-11-08, upload) Insert the photo row only after processing succeeds, so `pending` means "interrupted upload"; keep fingerprints of failed photos re-queueable.
- (2026-11-08, supabase) BEFORE triggers on a table fire alphabetically — a column guard that resets values must sort after triggers that need the attempted change (photos_enforce_cap < photos_protect_columns). Cap triggers must also fire on `update of book_id`.
- (2026-11-08, supabase) jsonb equality filter: `.filter('doc','eq','{}')`; `.eq(col, {})` sends "[object Object]". Storage errors: `statusCode` is a string ("403"/"409"/"415"), `status` is always 400.
- (2026-11-08, text) Never `String.slice` user text that ends up in jsonb — lone surrogates make Postgres reject it. Use `clipText` (src/lib/text/clip.ts); measure title limits in code points like `char_length`.
- (2026-11-08, next) App Router folders starting with `_` are private (not routes) — name temp pages `dev-*`. Route files may only export route fields; put helpers in src/lib. Don't let two agents share one `next dev` on :3000 (Fast Refresh + `.next` clobbering) — separate ports/`--output`, or build in a scratchpad copy.
- (2026-11-08, tsconfig) Target is ES2017: no regex `s` flag — use `[\s\S]`.
- (2026-11-08, mapbox) v6 reverse: first feature is most specific; `properties.context.{neighborhood,locality,place,region,country}.name` gives the hierarchy; UAE "neighborhood" can be broad ("Abu Dhabi Island"). Negative-cache failed lookups (place_checked_at, 24 h) or they're re-billed every run.
- (2026-11-08, testing) Hold a request with page.route → reload first, then unroute (unrouting first lets it complete). Use `request.get(..., { maxRedirects: 0 })` to assert redirects never leave the origin. Live e2e users: admin `generateLink` → `/auth/confirm?token_hash=…&type=magiclink` (no email sent); always clean up in afterAll.
- (2026-11-08, agents) A subagent can be cut off by the account usage limit — commit WIP on the branch before long reviews, then resume the same agent with SendMessage.
- (2026-11-09, claude-api) SDK 1.6.0 `zodOutputFormat().parse` throws on refusal/max_tokens text, hiding stop_reason — use a lenient format (return null) and check stop_reason first. The `timeout` request option only covers fetch until headers; enforce a hard per-call bound with your own AbortSignal, and pass `maxRetries: 0` per request when the caller budgets retries.
- (2026-11-09, ai-pipeline) Resumable ticks need: a lease token checked on every checkpoint/release (stale ticks must stop silently), the attempt number reserved in the cursor BEFORE each model call (else resumed calls are billed but deduped away), and atomic capped run creation (advisory lock per user) — counting then inserting races across parallel books.
- (2026-11-09, ai-pipeline) Never let the client choose build vs rebuild — derive it server-side (doc.meta.generator / finished live run), or the rebuild cap is bypassed.
- (2026-11-09, supabase) Supabase default privileges grant EXECUTE on new public functions to `authenticated` — revoke explicitly. Changing an RPC's return type needs drop + create. FK set-null/cascade actions run as the table owner without RLS. After column-level grants, use has_column_privilege (has_table_privilege is false).
- (2026-11-09, supabase) A step logger that re-sums totals from step rows stays correct under duplicate/ignored inserts; numeric(10,4) totals hide sub-cent replay costs — use (12,6).
- (2026-11-09, dupes) Union-find grouping chains: a loose time window joins separate bursts of the same scene. Tune the window on the time gaps of close-hash pairs (real data: bursts ≤ 98 s, then a gap) — 3 min, not 30.
- (2026-11-09, react/next) An SSR'd <img> that fails before hydration never fires onError — also check `complete && naturalWidth === 0` on mount. Kill only your own `next start` by PID; parallel agents need separate ports and scratchpad build copies (shared `.next` clobbers).
- (2026-11-09, agents) Long multi-agent milestones hit the account usage limit — commit WIP on the branch before each wave, and resume the same agents with SendMessage instead of respawning.
- (2026-11-09, ai-pipeline) A names allowlist must never include AI-written text (chapter/cover titles) or an invented name allowlists itself; once code name-checks model titles, ask the model for sentence case (Title Case reads as unknown proper nouns).
- (2026-11-09, ai-pipeline) Positional caption keys (m{n}:{k}) stay valid only if the structure they refer to is frozen — rebuild the doc from the stored plan each tick and re-map onto the pruned doc by page photos.
- (2026-11-09, ai-pipeline) Status copy must come from what the album actually is (doc meta.generator + missing captions), not from ai_status alone — 'partial' covers both rule fallback and an AI album where only the Critic failed. Count Critic failures separately from caption failures.
- (2026-11-09, ai-pipeline) A deterministic caption pre-check needs culture-aware allowlists (Eid, Ramadan, Mom/Baba/Teta, Happy Birthday, months present in dates) or every false positive costs a repair call; sentence-initial names, spelled-out numbers and Arabic names remain the Critic's job.
- (2026-11-09, ai-pipeline) Put a per-run USD cap with a pessimistic pre-call estimate in front of every optional model call (captions, critic, repair); worst case without it was ~$4.6 extra per paid build.
- (2026-11-09, layouts) Catalogue order decides layout ties (full-page beats one-portrait) — re-fits that must keep a caption need an explicit preferCaption.
- (2026-11-09, supabase) JSON.stringify writes lone surrogates as \udXXX escapes that Postgres jsonb rejects — check the stringified text before writing. Removing a jsonb key with supabase-js is read-edit-write and races with a lease holder's next checkpoint.
- (2026-11-09, testing) `cp -R` into a scratchpad copy whose node_modules is a symlink writes into the repo — rsync with node_modules excluded. Replay ticks are ~0 ms, so short states (captioning) may never reach the client; assert copy in unit tests.
- (2026-11-09, react) A native <details>/<summary> disclosure needs no client JS. To keep a client component's message across router.refresh() when the server swaps content, render it at the same tree position in both branches.
- (2026-11-10, supabase) Making a column server-only via the guard trigger makes remaining user-scoped writes "succeed" while silently keeping the old value — grep every writer and move it to admin + owner filter before the migration lands; deploy code before such a migration.
- (2026-11-10, ai-pipeline) When two run kinds share one table, give the second its own state the first kind's machinery never claims, filter every lookup by kind, refuse other kinds before claiming, and have the create RPC reap its own stale rows. A "max N in flight" rule without a lease needs a staleness window.
- (2026-11-10, testing) Parallel subagents need their own scratchpad/app-<task> build copy and port; a shared .next gets clobbered. Vitest 5/Vite 8 needs `oxc: { jsx: { runtime: "automatic" } }` + `.test.tsx` include for component tests when tsconfig has jsx: preserve. Tests importing server modules for parity need vi.mock("server-only").
- (2026-11-10, react) StrictMode double-mounts effects — don't dispose long-lived schedulers in effect cleanup. A smooth scrollTo emits intermediate scroll events; a scroll→store sync must ignore them while its own programmatic scroll runs. Items keyed by id get re-snapped by the browser when pages are inserted before them.
- (2026-11-10, e2e) macOS has no `timeout`; Playwright --global-timeout skips afterAll and leaves live test users behind — use per-test timeouts for live specs.
- (2026-11-10, next) To share one DB read between generateMetadata and the page, put React `cache()` in the module that does the read — a wrapper module importing it back creates a circular import. cache() is per-request and passes through outside a render (route handlers).
- (2026-11-10, testing) Chrome heap snapshots no longer label detached DOM "Detached …" — count nodes whose node_fields "detachedness" === 2, and always measure a baseline build to prove the probe can see a leak (heap script: session scratchpad heap/heap.mjs).
- (2026-11-10, react) page-flip can't be destroyed (rAF loop runs forever): after removing handlers, null its page collection/render/UI refs but keep own no-op drawFrame/animation fields so the loop can't throw — verified 0 detached nodes over 20 rotations.
- (2026-11-10, agents) When the usage limit kills subagents, their transcripts survive in ~/.claude/projects/<proj>/<session>/subagents/*.jsonl — recover the exact briefs + last state from there, commit the WIP, and respawn with a RESUME brief listing the failing tests.
- (2026-11-10, testing) The PGlite dry-run harness lives in session scratchpads and disappears — rebuild it (pglite in scratchpad, stub roles anon/authenticated/service_role[bypassrls], auth.uid/role/jwt via request.jwt.claims, storage.buckets/objects/foldername, Supabase-like default privileges); consider committing it under scripts/ to stop re-building.
- (2026-11-10, testing) The PGlite dry run is committed: `npm run db:dry-run` (scripts/pglite; flags --until, --rls=<file|->, --no-rls). Don't rebuild it in a scratchpad.
- (2026-11-10, stripe) Checkout `expires_at` must be ≥ 30 min after Stripe's own creation time — use 31 min. Idempotency keys need identical params: round nowSec to the key's bucket and hash params into the key; after a 23505 on replay, check whether the pending order already holds the same session before expiring "yours".
- (2026-11-10, stripe) Adaptive Pricing can present another currency — disable it (`adaptive_pricing: {enabled:false}`) or validate `currency_conversion.source_*`, else a real payment fails your amount check. A paid session that fails validation means money moved: error-log it and park the order, never just warn.
- (2026-11-10, stripe) Livemode mismatch is asymmetric: live event on a test-key deploy → 5xx so Stripe retries; test event on a live deploy → 200 ignore. Webhook tests can sign real events with `stripe.webhooks.generateTestHeaderString` and a dummy whsec.
- (2026-11-10, next) Unit-test the middleware matcher with `unstable_doesMiddlewareMatch` (next/experimental/testing/server). Client components importing a "use server" action pull its server-only imports into vitest — vi.mock the actions module and keep a router-free *View for static-render tests. Constants exported from a "use client" module become client references in server components — keep shared constants in plain modules.
- (2026-11-10, e2e) Signed-out specs need dev-* fixtures (404 in prod builds) → run them on `next dev`; live specs on `next start`, separate copies/ports. Playwright transpiles imported .mjs helpers to CJS — no import.meta. Live-spec selects must not name columns of a pending migration. Doc padding helpers must keep each layout's slot count (photoId null) — page_limit masks a malformed pad on free books.
- (2026-11-10, supabase) In PL/pgSQL `if f() = 'x' or exists(select …)` the subquery uses the statement snapshot and misses rows f() just wrote — assign first, check in a separate statement.
- (2026-11-10, ux) Return-page copy may only state what the server confirmed — "haven't had confirmation yet", never "payment received".
- (2026-11-10, pdf) Chromium/Skia embeds variable web fonts (next/font Google) as Type3 — print with next/font/local static per-weight files (unique const names, else they merge with root-layout faces); check font subtypes with scripts/pdf-inspect.mjs, not by eye. pdf-lib object streams hide /Type3 from byte greps.
- (2026-11-10, pdf) Chromium quantises @page size (154×216 mm → 437.04×612 pt) and lays out from top-left — derive TrimBox/BleedBox from the real MediaBox's top-left.
- (2026-11-10, pdf) Print render time is Storage downloads, not encoding: prefetch, 8–12 downloads in flight, separate CPU limit for sharp; baseline JPEG quantisationTable 3 q80 beats mozjpeg on speed at equal quality. sharp drops metadata unless withMetadata; Next 15.5 already externalises sharp.
- (2026-11-10, vercel) Fluid compute serves concurrent requests per instance — heavy jobs (Chromium) need a per-process single-flight guard taken before the DB claim. vercel.json `functions` keys are globs: `*` for `[id]`. A deadline via Promise.race doesn't stop work — thread an AbortSignal and kill the browser.
- (2026-11-10, db) A rate cap that counts rows breaks if cleanup deletes rows — mark rows superseded instead. Version derived outputs (renderer_version) and key reuse on it so renderer fixes reach old exports.
- (2026-11-10, e2e) The PDF renderer opens NEXT_PUBLIC_APP_URL — scratch servers on other ports must build/start with it set to their own origin. Live-spec migration probes must call the current RPC signature. Don't time renders while another next dev suite runs. Playwright setInputFiles refuses >50 MB of in-memory buffers — use file paths.
- (2026-11-10, retention) A deletion that relies on "warning sent" must only count a warning after the provider accepted it (claim → send → confirm), give the email phase its own time budget, and show the deletion date in the UI for users who opted out of email. A generic updated_at trigger must ignore housekeeping columns or claims reset idle clocks.
- (2026-11-10, supabase) Deploy order differs per migration: additive schema the code needs → migration first; semantics the OLD code would misuse (e.g. claim no longer = sent) → code first, migration same day. Write the order into LAUNCH.md and the migration header.
- (2026-11-10, testing) Never send the real CRON_SECRET to a server on the live DB key — test the authorised path with an invalid SUPABASE_SECRET_KEY (fails closed). Keep temp Playwright configs in the scratchpad; "git add -A" sweeps them into commits.
- (2026-11-10, analytics) posthog-js drops headless-browser events (HeadlessChrome brand + navigator.webdriver) and `ip:false` is a no-op — discard IPs in project settings. @sentry/nextjs v11: withSentryConfig from @sentry/nextjs/config; ~39 kB shared JS even with tracing off.

- (2026-11-10, next) opengraph-image inside a route group is served at a hashed URL — read og:image from the page in tests. Vercel `functions` globs: `*` for `[id]`; vercel.json has no comments.
- (2026-11-10, schema) Version the in-memory doc but write the old version whenever no new feature is used — existing data stays byte-identical and rollback stays safe. Freeze rendering with byte-level goldens (tags one per line, GOLDEN_UPDATE=1 to regenerate, orphan check) BEFORE refactors; add format support by keeping the old class and adding inline styles only for new formats.

- (2026-11-10, validation) When one field widens its allowed id set (backgrounds may use dropped photos), give validators a separate id set for that field — otherwise the narrowest caller (Update album) rejects valid docs.
